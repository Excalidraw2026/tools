# 免费在线小工具

三个日常最常遇到的小事，全部在浏览器里完成，文件不上传、不注册、不收费。

## 有什么

| 工具 | 干什么 | 地址 |
|---|---|---|
| 图片压到指定大小 | 告诉它多少 K，压到刚好卡线。批量不乱序 | `/tools/img-compress.html` |
| 图片转 PDF | 多张照片按顺序合成一个 PDF，A4 或原图尺寸 | `/tools/img2pdf.html` |
| 拼长图 | 多张图上下拼或左右拼成一张，画质不掉 | `/tools/stitch.html` |

线上地址：https://excalidraw2026.github.io/tools/

## 为什么「不上传」不是宣传话术

这三个工具都没有后端。图片是用浏览器的 Canvas 和 Blob API 在你自己的设备上算完的，
生成的文件直接落进你的「下载」目录，中间不经过任何服务器。

断网也能用——这一点可以自己验证：打开页面，关掉 WiFi，功能照常。

## 技术上怎么做的

- 没有框架，没有构建步骤，没有 npm 依赖
- 图片压缩：Canvas 导出 + 二分法逼近目标字节数，尺寸优先，尺寸降不下来才等比缩小
- 图片转 PDF：手写 PDF 对象结构，JPEG 用 `DCTDecode` 直接嵌入，不重新编码
- 拼长图：Canvas 拼接，超过设备画布上限时自动等比缩小
- 批量下载：手写 ZIP（Store 模式），文件名按原顺序编号

## 已知限制

- 一次处理建议不超过 20 张，手机内存有限
- 拼长图单边超过 15000 像素会自动缩小，这是移动端浏览器的硬上限
- 不做 PDF 转 Word、不做抠图换背景，这些需要 OCR 或模型，纯前端干不了
